# LYRICA Music — Website Layout Clone ⭐

A modern music streaming homepage recreated from scratch using HTML and CSS as part of the **CSS Layout Clone: Flexbox, Grid & More | LF 2026** challenge by μLearn Foundation.

## 📌 About the Project

This project recreates a modern music streaming homepage layout using HTML and CSS.

The main goal was to practice building a structured webpage using **CSS Grid and Flexbox**, while making the layout responsive across desktop, tablet, and mobile screen sizes.

## ✨ Features

- Modern dark-themed music streaming interface
- Responsive navigation bar
- Search bar
- Library sidebar
- Playlist and podcast sections
- Hero section
- Trending songs section
- Popular artists section
- Popular albums and singles section
- Responsive footer
- Hover effects for buttons, links, and cards
- Responsive layouts for desktop, tablet, and mobile

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## 🎨 CSS Concepts Used

### CSS Grid

CSS Grid is used for:

- Overall page layout
- Song card grids
- Artist card grids
- Footer layout

### Flexbox

Flexbox is used for:

- Navigation bar
- Search bar
- Library header
- Section headers
- Buttons and component alignment

### Responsive Design

Media queries are used to adapt the layout for:

- Desktop
- Tablet
- Mobile

The number of cards per row and the visibility of the sidebar and navigation elements change according to the screen size.

### Hover Effects

Hover effects and transitions have been added to:

- Buttons
- Navigation links
- Song cards
- Artist cards
- Footer links
